Cloud S3

Lưu trữ đối tượng, chuẩn S3.

Lưu file, ảnh, video, bản sao lưu và log với API chuẩn S3. Dùng ngay công cụ bạn quen, dữ liệu lưu trong nước.

Đi cùng Cloud Server

Máy chủ chạy ứng dụng, Cloud S3 giữ file.

Ứng dụng trên Cloud Server đọc ghi bucket qua API S3. Ảnh công khai được người dùng tải thẳng từ bucket, máy chủ không phải gánh. Bản sao lưu nằm trong bucket riêng tư. Tài liệu cần gửi cho khách đi qua link có thời hạn. Cả hai dịch vụ do DCNET vận hành, một đầu mối hỗ trợ.

Vuốt ngang để xem cả sơ đồ

  • 1. Ảnh, videoỨng dụng lưu file vào bucket công khai, người dùng tải thẳng từ bucket.
  • 2. Sao lưuĐẩy bản sao lưu cơ sở dữ liệu vào bucket riêng tư theo lịch, bằng rclone hoặc aws-cli.
  • 3. Chia sẻ fileGửi link tự hết hạn, không mở công khai cả bucket.
  • 4. Một đầu mốiĐội ngũ DCNET hỗ trợ cấu hình công cụ sao lưu, đồng bộ.

01

Dùng như S3, không phải học lại.

Tương thích API S3

Ứng dụng đang dùng S3 chỉ cần đổi endpoint và khoá truy cập.

Công cụ quen thuộc

aws-cli, rclone, s3cmd và các thư viện S3 cho Python, Node.js, Java, Go, PHP.

Bucket, object và phân quyền

Đặt từng object công khai hoặc riêng tư, phân quyền cả bucket bằng bucket policy.

Link chia sẻ có thời hạn

Tạo đường dẫn tải file tự hết hạn, không cần mở công khai cả bucket.

Dung lượng theo nhu cầu

Không cần chọn trước kích thước ổ. Lưu thêm khi dữ liệu tăng.

Dữ liệu lưu trong nước

Giúp doanh nghiệp đáp ứng Luật Bảo vệ dữ liệu cá nhân và Luật An ninh mạng.

Lưu nhiều phiên bản

Bật versioning để giữ các bản cũ của file, lấy lại khi lỡ ghi đè hoặc xoá nhầm.

Khoá chống xoá

Object Lock giữ file không thể xoá, sửa hay ghi đè trong thời gian bạn đặt. Bản sao lưu an toàn hơn trước mã độc tống tiền.

Vòng đời dữ liệu

Đặt quy tắc tự xoá file cũ sau số ngày định trước, ví dụ log quá 60 ngày.

Mã hoá

Truy cập qua HTTPS. Mã hoá dữ liệu khi lưu, dùng khoá của nền tảng hoặc khoá do bạn cung cấp.

Web tĩnh và CORS

Chạy website tĩnh từ bucket. Cấu hình CORS để trình duyệt tải file thẳng từ bucket.

Gắn như ổ đĩa, quản lý bằng mã

Gắn bucket vào máy chủ Linux như một thư mục. Tạo bucket, đặt quy tắc bằng Terraform.

Câu hỏi về Cloud S3

Ứng dụng của tôi đang dùng S3, chuyển sang có khó không?

Thường chỉ cần đổi endpoint và cặp khoá truy cập trong cấu hình. Đội ngũ DCNET hỗ trợ kiểm tra khi bạn chuyển.

Dữ liệu được lưu ở đâu?

Tại Việt Nam. Dữ liệu lưu trong nước.

Bản sao lưu có bị mã độc tống tiền xoá không?

Bật khoá chống xoá (Object Lock) cho bucket sao lưu. Ở chế độ tuân thủ (compliance), trong thời gian giữ không ai xoá, sửa hay ghi đè được file, kể cả tài khoản quản trị.

Lỡ xoá hoặc ghi đè file thì sao?

Nếu bucket bật lưu nhiều phiên bản, bạn lấy lại được bản trước đó. Bản cũ vẫn tính vào dung lượng lưu trữ.

Giá tính thế nào?

Liên hệ đội ngũ DCNET để nhận báo giá theo nhu cầu lưu trữ của bạn.

Tôi dùng công cụ nào để quản lý file?

Bất kỳ công cụ hỗ trợ S3: aws-cli, rclone, s3cmd, hoặc các ứng dụng quản lý file có hỗ trợ S3.

Cần chỗ lưu dữ liệu cho hệ thống của bạn?

Kể nhu cầu lưu trữ của bạn, đội ngũ DCNET tư vấn cấu hình và gửi báo giá.
